CL2 · Clone a bot whose model is goneApprovedThe usual way to fix a bot that cannot run (UI-6.2). The model field starts empty with the reason under it (E1 style), step 4 shows the red "!", and the preview Model section shows the red (!) (E3 style). Create is off until you pick a model. The Tools list shows only internal tools until a model is picked, because provider tools depend on the model. The same rule covers a skill version that went to Trash (D49): that skill row shows the red "!" on step 3, and you pick another version or untick it.
