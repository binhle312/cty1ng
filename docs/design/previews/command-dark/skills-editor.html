Round 8 · Skills pages: editor states (layout B)

Every state of the editor in layout B. The limits are name 64, description 1,024 and body 20,000 characters (owner, 2026-10-23). Labels and messages use Simplified Technical English. All cards are approved (owner, 2026-10-23).

Kind36 px · 30 pxUse it for
PrimarySaveSaveThe one main action of a page, card or dialog: Save, Create, Apply, Approve. At most one in each area.
SecondaryCancelCancelEvery other action: Cancel, Discard, Clone, Import, Back.
DangerDeprecateDeprecateAn action that removes or hides something, and that you can undo: Deprecate, Let them go, Delete project.
Danger fillDeleteDeleteOnly the last step of a delete, in its confirm dialog: Delete project.
DisabledSaveSaveThe same button at 40% opacity, for example Save with no changes or with an error. The tooltip says why.
DefaultStayCancelThe button that Enter presses gets a focus ring. In a dialog that removes something, Cancel is the default.
Order
CancelSave changesLet them goStay on this pageButtons go at the right. The primary button is last, at the far right. Secondary and danger buttons go to its left.
Check boxes
Ticked: amber fill with a ✓Not ticked: border onlyOff: cannot changeA ticked box always shows the ✓, so the state does not depend on colour only.
Two sizes: 36 px (page, dialog and save bar) and 30 px (headers, cards, lists). The radius is 8 px. The label is a verb, in sentence case.

C1 · New skillApproved+ New adds a "New skill" item at the top of the list and opens an empty editor. Only a new skill has the Slug field. Name comes first, and Slug is next to it. While the slug is empty or not edited, the app makes it from the name: lowercase, spaces become "-", accents are removed ("Viết câu" → "viet-cau"). After you edit the slug, the app stops. The slug is fixed after Create (D19). Only the field in focus gets a highlighted border. Every field is required. Create stays off until every field has text. A field that you leave empty shows "Type a name.", "Type a description." or "Type the steps." The grey text is an example, not a value.
