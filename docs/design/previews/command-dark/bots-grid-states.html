S7 · Health: when a bot needs attentionApprovedHealth is computed from data the app has; nothing new is stored. Two levels, shown as one line above the status and as the card border colour. Healthy bots show nothing. Cannot run (red, "!" badge): no API key, or the model is not in the catalog. Needs attention (amber), the first that applies: "2 of the last 5 runs failed"; "3 runs stopped at the request limit this week"; "Uses a deprecated skill"; "Last run cut history to fit the context". Skill updates are not a health problem; they stay in the skills line. Waiting for you is a state, not health. The edit layout (L1) lists every problem with a fix. Thresholds are open for your call (see the thread).
