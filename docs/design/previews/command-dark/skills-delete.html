D7b · Delete dialogApprovedThe dialog lists the bots that use the skill, with no tick boxes: the delete always takes the skill off every bot, so this is a required step (owner, 2026-10-23). The skill goes to Trash for the number of days in Settings (one Trash setting for skills and projects, default 30), then the app deletes it for good. Old runs point to the version by its id and keep a copy of the slug and version number, so a chat shows "write-user-stories v4 (deleted)" and never links to a new skill with the same slug. On restore from Trash, the app suggests to assign the skill again to the bots that used it, but only to bots that are still active, not to bots in Trash (owner, 2026-10-23). The app keeps that list of bots with the trashed skill. Cancel is the default.
