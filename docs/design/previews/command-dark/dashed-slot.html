DS1 · Dashed slot: one look for "something can go here"ApprovedName: dashed slot (docs/design/components/dashed-slot.md). It marks an empty place that the owner can fill: by a click (New project, add a bot) or by a drop (pin, add to conversation). Two states only. Rest: 1.5 px dashed outline-strong border, on-surface-muted text, no fill. Active: 1.5 px dashed primary border, primary text, primary-tint fill (#3A2E12 in Command) — the New project tile in left-bar.png. The shape follows the thing it stands for: tile, circle, pill or card. Every case we drew this round is in the table.

DS2 · Two helpers that are not slotsApprovedWhile an item moves, its old place is a gap: a dashed outline border (the faint one), no text, no fill. Where it will land shows a drop line: 2 px primary at 80 %. They are part of the drag, not slots: nothing can be clicked there. Rules for all three: no animation except a 120 ms fade between rest and active; the dashed border never carries meaning alone, the text or the + says what the place is for; focus on a clickable slot shows the standard focus ring (C0).
