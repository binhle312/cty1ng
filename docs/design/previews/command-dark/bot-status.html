ST1 · One status standard: words, icon, colourApprovedYour note (07:57): running and waiting had the same amber. New rule: amber means "you are needed" and only Waiting for you uses it (as the approved amber "?" badge). Red means a problem: failed, paused at the cap, cannot run. Running is the normal text colour with the spinner in the bot colour: work goes on, nothing to do. Grey is quiet: idle, queued, waiting for another bot. Each state has one icon, used in the avatar badge, the card status line, the bot card status row and the Flow view. A status that names a conversation is a link to that conversation.
