D3 · Import previewApprovedImport (in the list header) takes a zip of SKILL.md folders. The app reads it and changes nothing yet. One zip can hold new skills and new versions of skills that you have: the app matches each folder to a skill by its slug. The table groups the folders: New skills, New versions of your skills (with the changes), No change, and Skipped (with the reason). Each good row has a box, and every box starts ticked. Untick a skill to leave it out. Apply writes the ticked rows in one transaction and skips the rest. A folder can also have scripts or other files: the app imports only SKILL.md and lists the skipped files, because bots have no tool that runs code.

D6 · ExportApprovedExport (in the list header) opens a card with every active skill (deprecated skills are not in it). Every box starts ticked, and Select all ticks or unticks all. Export n skills downloads one zip, named <n>-skills-<UTC timestamp>.zip, for example 6-skills-20261023T035956Z.zip. The timestamp uses the ISO 8601 basic format with no ":", so the name works on every OS. The zip holds the latest version of each active skill as <slug>/SKILL.md. After the download, the toast says "Exported 6 skills to 6-skills-20261023T035956Z.zip." Cancel, Esc or a click outside closes the card.
