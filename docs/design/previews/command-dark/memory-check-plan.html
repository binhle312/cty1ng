S4 · Check result: items disagreeApprovedWhen the check finds disagreements, the line says how many, and "Review in Memory" opens the Memory pane on the right with a proposal card, as Tidy memory does. Each item shows the memory item and the instruction line, and you pick what wins: Instructions win (the app updates or deletes the memory item), Memory wins (the app changes the instruction line), or Decide later (nothing changes yet; the next plan that touches it asks you, S4b). The line under the choice shows the result. The app picks Instructions win first. Nothing changes until you apply. A change to the instructions from this card does not start a new check. With no disagreements, the line says "no conflicts" and nothing opens.

S4c · Request changes: the note boxApprovedRequest changes opens a note box inside the plan card, in place of the three buttons, with the focus in it. The plan stays open above it, so you can read the step that you want to change. The box takes Markdown. The Preview tab is nice to have, not in the first build (owner, 2026-10-22); when it ships, it renders with raw HTML off. Send stays off until the box has text. Enter sends. Alt+Enter adds a line (Shift+Enter does too). Esc or Cancel closes the box and brings the buttons back. If you type in the normal message box instead while the plan waits, the app treats your message as a change request for that plan.
