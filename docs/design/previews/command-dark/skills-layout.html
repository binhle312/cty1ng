B2 · History panel and diffApprovedHistory opens a floating panel on the right. Versions are newest first, with the changelog line, who saved it, when, and which bots use it. A click on a version shows the changes from that version to the latest in the main area, read-only, with Restore. Compare picks any two versions (UI-7.5). Restore makes a new version with the old content (v5 here), so no version is lost. Esc or ✕ closes the panel, and Back to editor returns to Write.
