Glossary
The words that the Login app stories, screens and tests use. Use these words, not other words for the same thing.
WordMeaning
Sign-inThe flow where a user enters the email first, then the password.
Magic linkA one-time link that the app sends by email. It is valid for 15 minutes.
LockoutAfter 5 wrong passwords, the account waits 15 minutes before the next try.
Reset codeA 6-digit code for a password reset. The user types it on the reset page.
Trusted deviceA device where the user ticked “Keep me signed in”. It skips the code for 30 days.
Not used
“Log in” and “login” as a verb. The stories say “sign in”.
