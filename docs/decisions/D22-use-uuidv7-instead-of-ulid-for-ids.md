# D22. Use UUIDv7 instead of ULID for ids

Status: accepted (2026-10-21)
Decision: Primary keys are UUIDv7 (RFC 9562) instead of ULID. Like ULID they are unique and
sortable by creation time; unlike ULID they are a standard UUID, stored natively by Postgres
(`uuid` type) in the VPS phase, and generated by Python's standard library from 3.14
(`uuid.uuid7()`), or a small package before that.
Why: Same properties as ULID with better ecosystem support.
Rejected: ULID (fine, but non-standard); UUIDv4 (random, so inserts scatter across indexes and
ids do not sort by time); auto-increment integers (leak counts, clash when merging data).
Consequences: Ids are 36 characters in URLs instead of 26.
