# backend

The Node process: Hono HTTP API, SSE stream, Drizzle on SQLite (architecture.md §1–§4).

| File | What it is for |
| --- | --- |
| `package.json` | Scripts: `dev`, `start`, `cli`, `db:generate`, `db:migrate`, `db:check` |
| `tsconfig.json` | Strict TypeScript settings for `src/` and `test/` |
| `drizzle.config.ts` | drizzle-kit settings: SQLite, schema in `src/adapters/db/schema.ts` |
| `migrations/` | SQL generated by drizzle-kit, reviewed like code (never edited by hand) |
| `src/` | `app/` (composition root), `core/` (ports, services, rules), `adapters/` (one folder per system) |
| `test/` | `contracts/` (one suite per port), `api/`, `security/`, `fixtures/`, `support/` (test app, SSE reader) |

Start here: `src/app/compose.ts`. Do not: import an adapter from `core/` or another adapter
(architecture.md §4.1; `pnpm lint` fails).
