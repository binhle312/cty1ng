Rule: When you compare designs for the owner, build a throwaway prototype of each option, run the same cases on each, and give measured numbers. Work that is already done is never a cost of the other option.
Owner said: "Two rounds reviewed the code is not a cost." (2026-11-13)
How to apply: Give the lines that each option adds and removes, what it depends on, and each difference in behaviour. Mark an estimate as an estimate. Keep the prototypes with their run command, so that a second opinion can run them again.
