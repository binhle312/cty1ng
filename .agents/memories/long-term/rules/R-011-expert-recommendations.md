Rule: Before you write the options of a question, write what a world-class expert would do. Recommend that. Never recommend an option because it is easier or less work for the agents.
Owner said: "do not suggest the option that make the work easily or less work for you" (2026-11-18)
Owner said: "Answer should solve the actual problem, not make your work easier" (2026-11-18)
How to apply: The expert answer fixes the root cause, prefers a machine check to a written step, follows the existing rule before it adds an exception, and fixes small real bugs. Add it as an option if the list lacks it. Give the cost honestly; the cost alone never decides.
