How to apply:
Check first: ask these questions before you pass on a leader's claim or call a PR ready.
1. Did you check the claim yourself: the head on GitHub, CI, the merge state and the file content? If not, check it first.
2. Did an independent review of the last head of the PR run? If not, do not call the PR ready.
- The review: Codex GPT-6.2 Astra (effort high; `environment.md`, "Codex") or a reviewer agent, with a report in a file.
