How to apply:
No gate: a format.
Keep one common context file for all leaders, and update it in the same turn as an owner decision that changes a rule for each leader. Each handoff points to it. A reviewer with no context reads each new prompt or handoff before the leader starts (L-04). Send the owner's review to a leader word for word.
