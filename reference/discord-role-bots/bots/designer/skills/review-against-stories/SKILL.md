# Review designs against stories

Use this when the owner requests changes, or new stories were approved after designs exist.

1. Read docs/stories.md, design/README.md and the owner's feedback.
2. Build a table in your reply: story id, screen file, status (covered, changed, missing).
3. Update only the screens that need it. Keep unchanged files untouched so the review stays small.
4. Update design/README.md, including the "Gaps" section.
5. Propose the handoff again with only the files you changed, and say what changed in the summary.
